# Dynamic JavaScript DOM Logic & RESTful API Client

## Project Overview

This project is a dynamic JavaScript web application that uses a public RESTful API to fetch and display product data. It provides interactive features such as real-time search, category filtering, sorting, cart management, loading states, and error handling.

## Features

* Fetches product data from the FakeStore REST API
* Uses `fetch()` with `async/await`
* Real-time product search
* Category-based filtering
* Sort products by price and name
* Add products to cart
* Stores cart data using `localStorage`
* Displays loading states
* Displays user-friendly error messages
* Dynamically updates the DOM
* Responsive product cards

## Technologies Used

* HTML5
* CSS3
* JavaScript
* JavaScript ES Modules
* RESTful API
* FakeStore API

## How to Run

1. Open the project in Visual Studio Code.
2. Open the `Client` folder.
3. Run `index.html` using the VS Code Live Server extension.
4. Open the application in the browser.
5. Use search, category filters, sorting, and Add to Cart features.
